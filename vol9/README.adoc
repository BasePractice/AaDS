= Раздел 4. Комбинаторика

Перестановки, размещения и сочетания: подсчёт количества и ленивое порождение.

|===
| Задача | Формула | Порождение

| Перестановки | n! | лексикографический порядок, следующая за O(n)
| Размещения | A(n,k) = n!/(n−k)! | —
| Сочетания | C(n,k) = n!/(k!(n−k)!) | лексикографический порядок индексов
|===

Наборы порождаются лениво: 12! — почти полмиллиарда перестановок, в памяти живёт ровно одна.

Прикладная задача раздела — криптарифметические ребусы «ОДИН + ОДИН = МНОГО»: перебор
подстановок цифр под буквы. Реализация лежит в `vol2` в пакете `yasymb`.
Ещё один порядок обхода перестановок — алгоритм Джонсона—Троттера — в `vol_` в пакете `jt`.
