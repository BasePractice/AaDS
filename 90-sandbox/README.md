# Песочница

Модуль вне программы курса: прикладные задачи, которые не легли ни в один раздел.
Лабиринт и «Жизнь» переехали в `16-mazes-life`.

| Пакет | Тема | Раздел курса |
|---|---|---|
| `prime` | решето Эратосфена, числа Мерсенна, Диффи—Хеллман | — |
| `machine/post` | машина Поста: компилятор и исполнитель | — |
| `codes` | Raptor-коды, распределение Робуста—Солитона | — |
| `cache` | двухуровневый кэш с инвалидацией через Redis | — |
| `object` | пул объектов с автовозвратом | — |
| `games` | текстовый квест с автопилотом | — |
| `buffer`, `trampoline`, `features` | кольцевой буфер, батут для хвостовой рекурсии, счётчик диапазонов | — |

Диаграммы двухуровневого кэша лежат в `docs/cache`.

## Практика по преобразованию Фурье

Откройте пакет [signal](src/main/java/ru/mifi/practice/boring/signal).
В `PlainFourier.direct` проследите сумму для одной частоты.
В `CooleyTukey.direct` найдите перестановку индексов и объединение пар.
Для четырёх отсчётов порядок индексов после перестановки равен 0, 2, 1, 3.

1. Запустите лекционный пример из корня проекта на JDK 17:

   ```bash
   mvn -pl 90-sandbox -am -Dtest=CooleyTukeyTest#matchesTheLectureSpectrum -Dsurefire.failIfNoSpecifiedTests=false test
   ```

2. В [тесте](src/test/java/ru/mifi/practice/boring/signal/CooleyTukeyTest.java)
   сверьте обе реализации на отсчётах `[3, 2, 1, 0]`. Коэффициенты от
   `k=0` до `k=3` равны `[6, 2−2i, 2, 2+2i]`. Тест сравнивает обе
   части каждого комплексного числа с допуском `1e-9`.
3. Предскажите спектр для `[1, 1, 1, 1]`. Подставьте этот сигнал и своё
   предсказание в копию теста и запустите его снова. Для самопроверки
   разберите, почему сумма для `k=0` равна 4, а остальные суммы взаимно
   сокращаются.
