= Раздел 11. Топологическая сортировка

Линейный порядок вершин ориентированного графа, при котором каждое ребро ведёт от более раннего
к более позднему. Существует только для графа без циклов.

|===
| Реализация | Идея | Сложность

| `Kahn` | очередь вершин с нулевой входящей степенью | O(V + E)
| `DepthFirst` | обход в глубину, вершина пишется при выходе | O(V + E)
|===

Обнаружение цикла: у Кана — в результат попали не все вершины; у обхода в глубину — встречена
серая вершина, то есть найдено обратное ребро. Обе реализации возвращают пустой результат.
