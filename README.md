# Алгоритмы и структуры данных

Практика к курсу «Алгоритмы и структуры данных».
[Презентация](https://docs.google.com/presentation/d/1wnUpkpPjfUgslAAFgakvIRrrGXmNPuwz/edit?usp=sharing).

## Сборка

Проект собирается **на JDK 17**. Начиная с JDK 23 javac отключает аннотационную обработку по
умолчанию — Lombok молча перестаёт генерировать код, и `vol8` не компилируется. Версия проверяется
`maven-enforcer-plugin`, поэтому сборка на другом JDK падает сразу и с понятным сообщением.

```bash
mvn -B clean package
```

Фаза `validate` прогоняет checkstyle и PMD, фаза `test` — JUnit 5.

| 5 | Сортировка | `vol3` |
| 6 | Поиск | `vol3` |
| 7 | Хеширование | `vol4` |

| 9 | Куча | `vol6/tree/Heap` |
| 10 | Система непересекающихся множеств | `vol10` |
| 11 | Топологическая сортировка | `vol11` |
| 12 | Остовные деревья | `vol12` |

Модуль `vol_` — песочница вне программы курса: кэши, Raptor-коды, машина Поста, простые числа,
пул объектов, текстовый квест.

Модуль [heroes](heroes) тоже вне программы и состоит из двух независимых приложений:
[heroes/game](heroes/game) — пошаговый бой на сетке со Swing-интерфейсом,
[heroes/web](heroes/web) — чат-комнаты на Spring Boot. Общего кода у них нет.

## Задания

Часть ошибок в коде оставлена намеренно и помечена в JavaDoc («В коде есть ошибка», «Найдите здесь
ошибку», «Почему реализация не оптимальна?»). Рядом с каждой лежит `@Disabled`-тест, описывающий
ожидаемое поведение: снимите `@Disabled`, добейтесь зелёного теста.
