## Практика HMAC-SHA-256

Из корня репозитория на JDK 17:

```sh
mvn -pl 06-hashing -am verify
java -cp 06-hashing/target/classes ru.mifi.practice.vol4.hash.HmacDemo
```

Пример использует открытый тестовый ключ из 20 байт `0x0b` и строку
`Hi There` в UTF-8. Сверьте тег с [RFC 4231, Test Case 1][rfc4231].
Ожидаемый вывод:

```text
Тег: b0344c61d8db38535ca8afceaf0bf12b881dc200c9833da726e9376c2e32cff7
Hi There: true
Hi there: false
```

Откройте `HmacSha256.java` и найдите подготовку блока ключа, применение
`ipad` и `opad`, внутренний и внешний хеши. Затем измените один байт в
`changed` и снова запустите пример с тем же тегом. Если байты отличаются
от исходных, проверка вернёт `false`.

`HmacSha256` раскрывает шаги [RFC 2104][rfc2104] для разбора на занятии.
Для прикладного кода Java предоставляет `javax.crypto.Mac` с алгоритмом
`HmacSHA256`.

[rfc4231]: https://www.rfc-editor.org/rfc/rfc4231.html#section-4.2
[rfc2104]: https://www.rfc-editor.org/rfc/rfc2104.html#section-2
