= Раздел 12. Остовные деревья

Минимальное остовное дерево: связный подграф без циклов, содержащий все вершины и имеющий
минимальную сумму весов. Ровно V−1 рёбер.

|===
| Реализация | Идея | Сложность | Когда удобнее

| `Kruskal` | рёбра по возрастанию веса, компоненты через СНМ | O(E log E) | разреженные графы
| `Prim` | дерево растёт от вершины, кандидаты в куче | O(E log V) | плотные графы
|===

Жадность работает благодаря свойству разреза: самое лёгкое ребро любого разреза входит
в некоторое минимальное остовное дерево.

Для несвязного графа обе реализации дают остовный лес. Крускал опирается на `vol10`.
