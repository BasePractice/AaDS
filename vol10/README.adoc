= Раздел 10. Система непересекающихся множеств

Отвечает на вопрос «лежат ли два элемента в одном множестве» и объединяет множества.

|===
| Реализация | find | union

| `Colored` — номер множества у каждого элемента | O(1) | O(n), перекраска всего множества
| `Compressed` — множество как дерево | O(α(n)) | O(α(n))
|===

Две эвристики: объединение по размеру подвешивает меньшее дерево под большее, сжатие путей
переписывает пройденные ссылки сразу на корень. Вместе дают обратную функцию Аккермана,
которая не превосходит четырёх для любого мыслимого n, то есть практически константу.

Применяется в разделе 12 в алгоритме Крускала — см. `vol12`.
