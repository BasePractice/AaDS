= Раздел 15. Строки

Поиск подстроки без возвратов по тексту.

|===
| Реализация | Идея | Сложность | Память

| `Knuth` | префикс-функция задаёт умный сдвиг при несовпадении | O(n + m) | O(m)
| `RabinKarp` | хеш скользящего окна, пересчёт за O(1) на сдвиг | O(n + m) в среднем | O(1)
|===

Префикс-функция для каждой позиции образца хранит длину наибольшего собственного префикса,
который одновременно является суффиксом. Она вынесена в публичный метод: сама по себе отвечает
на вопросы о периодах строки.

Рабин—Карп сравнивает хеши, поэтому совпадение проверяется посимвольно — коллизии неизбежны
по принципу Дирихле (раздел 7). Арифметика в `long`: при модуле около двух миллиардов
произведение не помещается в `int` — ровно та ошибка, что была в `vol4`.
