= Раздел 8. Графы

|===
| Пакет | Что внутри

| `graph` | граф списками смежности, вершины, рёбра, веса
| `graph.algorithms` | обходы в глубину и ширину, поиск цикла, Дейкстра, муравьиный алгоритм
| `graph.loader` | разбор текстового формата
|===

== Формат файла графа

Рёбра записываются подряд, без переводов строк: `{исходная,целевая,вес}`. Вес необязателен и по
умолчанию равен единице. Пример: `{a,b,1}{b,c}{c,a,5}`. Примеры лежат в `src/main/resources`.

== Сложности

|===
| Алгоритм | Сложность

| Обход в глубину и в ширину | O(V + E)
| Дейкстра на приоритетной очереди | O(E log V)
|===

Дейкстра требует неотрицательных весов: отсечение по посещённым вершинам иначе даёт неверный
ответ молча. Муравьиный алгоритм — эвристика: точного ответа не гарантирует, зато переносится
на задачи, где точный перебор невозможен.
