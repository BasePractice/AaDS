## Куча (занятие 8)

`Heap.Minimum` — минимум-куча на массиве с нульиндексной адресацией:
parent(i) = (i−1)/2, left(i) = 2i+1, right(i) = 2i+2.
Вставка и извлечение — O(log n), чтение минимума — O(1).
Пирамидальная сортировка поверх той же идеи лежит в `05-sorting-search`.

## Деревья поиска (занятие 12)

| Реализация | Гарантия высоты |
|---|---|
| `BinarySearchTree` | нет: отсортированный вход вырождает дерево в список |
| `AVL` | разница высот поддеревьев не больше единицы |
| `RBT` | высота не больше 2·log(n+1) |

`Main` в пакете `tree.search` печатает число шагов поиска — видно, как балансировка спасает
от вырождения.

## Код Хаффмана для файла (занятие 12)

`tree.huffman.Main` показывает коды символов строки. `tree.huffman.HuffmanFile` применяет
то же дерево к байтам файла. На JDK 17 выполните из корня репозитория:

```sh
mvn -pl 08-heap-trees -am verify
work=$(mktemp -d)
printf 'BOOBS BOOM' > "$work/example.txt"
codec=ru.mifi.practice.vol6.tree.huffman.HuffmanFile
java -cp 08-heap-trees/target/classes "$codec" compress "$work/example.txt" "$work/example.huf"
java -cp 08-heap-trees/target/classes "$codec" decompress "$work/example.huf" "$work/restored.txt"
cmp "$work/example.txt" "$work/restored.txt"
wc -c "$work/example.txt" "$work/example.huf" "$work/restored.txt"
```

`cmp` завершается успешно при полном совпадении. Ожидаемые размеры — 10, 34 и 10 байт.
Коды занимают 21 бит, то есть три байта после упаковки и дополнения нулями справа.
Заголовок занимает ещё 31 байт. Попробуйте другой короткий текст и сравните полные размеры.

Заголовок HUF1 состоит из четырёх байтов сигнатуры, двух байтов числа разных значений
и пар «байт, четырёхбайтовая частота». Декодер строит то же дерево. При равных весах
сначала выбирается лист, затем узел с меньшим минимальным байтом в поддереве.
Исходная длина равна сумме частот. Вход и восстановленный файл ограничены 65 536 байтами
исходных данных. Команды создают новые выходные файлы.

ZIP хранит записи файлов и каталог. Один из методов сжатия записей, DEFLATE, сочетает
ссылки на повторы с кодами Хаффмана. HUF1 хранит один поток байтов в собственном формате.

## Формат файла дерева

Построчно `владелец:{левый, правый}`. Пример в `src/main/resources/standard.tree`.
