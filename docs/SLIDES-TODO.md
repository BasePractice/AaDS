## Занятие 10: отрицательные веса

Шесть новых слайдов после слайда 539 (топологическая сортировка через DFS), перед маркером практики
540. Заголовки — в стиле раздела: «Тема / подтема». Код взят из
`07-graphs/src/main/java/ru/mifi/practice/vol5/graph/algorithms` и сокращён под слайд.

### Слайд 1. Кратчайшие пути / отрицательные веса

1. Дейкстра жадный: вершину с наименьшим расстоянием он закрывает и больше к ней не возвращается.
2. Это верно, пока веса неотрицательны: любой обходной путь только длиннее.
3. Граф: a → c (2), c → d (1), a → b (5), b → c (−4).
4. Дейкстра закрывает c с расстоянием 2, затем d с расстоянием 3. Путь a → b → c стоит 1, но c уже
   закрыта, и d остаётся с ошибочной тройкой вместо двойки.
5. Отрицательные веса — не экзотика: возврат денег, выигрыш по времени, разность потенциалов.

### Слайд 2. Кратчайшие пути / Беллман — Форд

1. Не выбираем лучшую вершину — перебираем все дуги подряд и ослабляем каждую: если через дугу
   u → v выходит короче, запоминаем.
2. Повторяем круг за кругом, пока расстояния меняются.
3. Кругов не больше V − 1: кратчайший путь без циклов проходит не больше V − 1 дуги, а каждый круг
   продлевает правильный путь хотя бы на одну.
4. На графе из прошлого слайда: круг 1 — b = 5, c = 2, d = 3, затем по дуге b → c c = 1; круг 2 —
   d = 2; круг 3 ничего не меняет, стоп.
5. Цена — O(V · E) против O(E log V) у Дейкстры.

### Слайд 3. Кратчайшие пути / Беллман — Форд, код

```java
public Map<Vertex, W> distances(Graph graph, Vertex source) {
    graph.getVertices().forEach(vertex -> distances.put(vertex, INFINITY));
    distances.put(source, ZERO);
    for (int round = 1; round < graph.size(); round++) {
        if (!relaxed(graph, distances)) {
            return distances;
        }
    }
    if (relaxed(graph, distances)) {
        throw new IllegalStateException("Negative cycle leaves the shortest path undefined");
    }
    return distances;
}

private boolean relaxed(Graph graph, Map<Vertex, W> distances) {
    boolean changed = false;
    for (Edge edge : graph.edges()) {
        W known = distances.get(edge.source());
        if (!known.equals(INFINITY)) {
            W distance = known + edge.weight();
            if (distance < distances.get(edge.target())) {
                distances.put(edge.target(), distance);
                changed = true;
            }
        }
    }
    return changed;
}
```

Полный код — `BellmanFordShortestPath`.

### Слайд 4. Кратчайшие пути / отрицательный цикл

1. Граф: a → b (1), b → c (−1), c → b (−1). Каждый круг по b → c → b уменьшает путь на 2.
2. Кратчайшего пути нет: его можно сделать сколь угодно коротким.
3. Беллман — Форд это замечает: после V − 1 кругов делаем ещё один. Если расстояние всё ещё
   уменьшилось — в графе есть цикл отрицательного веса.
4. Бесконечность не складываем: из недостижимой вершины дуги не ослабляются, иначе сумма
   переполнит вес.
5. Чтобы показать сам цикл, запоминайте, из какой вершины пришло последнее улучшение, и идите по
   этим ссылкам назад — как при выводе цикла в топологической сортировке.

### Слайд 5. Кратчайшие пути / Флойд — Уоршелл

1. Задача шире: кратчайшие расстояния между всеми парами вершин.
2. Таблица V × V — та же матрица смежности: на диагонали 0, по дугам их вес, остальное — ∞.
3. Вершины по очереди пробуем как промежуточные: если из i в j через k короче известного,
   записываем d[i][j] = d[i][k] + d[k][j].
4. После круга по всем k в таблице кратчайшие пути с любыми промежуточными вершинами.
5. Отрицательные веса допустимы. Отрицательный цикл виден на диагонали: d[i][i] < 0.

```java
for (Vertex middle : vertices) {
    for (Vertex source : vertices) {
        for (Vertex target : vertices) {
            if (d[source][middle] + d[middle][target] < d[source][target]) {
                d[source][target] = d[source][middle] + d[middle][target];
            }
        }
    }
}
```

Полный код — `FloydWarshallShortestPath`.

### Слайд 6. Кратчайшие пути / что выбрать

| Алгоритм | Задача | Веса | Время | Память |
|---|---|---|---|---|
| Дейкстра на куче | от одной вершины | ≥ 0 | O(E log V) | O(V) |
| Беллман — Форд | от одной вершины | любые, ловит отрицательный цикл | O(V · E) | O(V) |
| Флойд — Уоршелл | все пары | любые | O(V³) | O(V²) |

1. Все веса неотрицательны — Дейкстра.
2. Есть отрицательные — Беллман — Форд.
3. Нужны все пары на плотном графе — Флойд — Уоршелл: V запусков Беллмана — Форда при E ≈ V²
   стоят O(V⁴).
