# Раздел 4. Комбинаторика

Подсчёт количеств, комбинаторные числа и ленивое порождение наборов.

| Задача | Формула или идея | Порождение |
|---|---|---|
| Перестановки | n! | лексикографический порядок, следующая за O(n) |
| Размещения | A(n,k) = n!/(n−k)! | — |
| Сочетания | C(n,k) = n!/(k!(n−k)!) | лексикографический порядок индексов |
| Размещения с повторениями | n^k | лексикографический порядок кортежей |
| Сочетания с повторениями | C(n+k−1,k) | неубывающие кортежи |
| Подмножества | 2^n | битовые маски |
| Разбиения числа | p(n) | невозрастающие слагаемые |
| Код Грея | 2^n наборов | отражённый двоичный код |
| Перестановки Хипа | n! | обмены по массиву счётчиков |
| Перестановки Джонсона — Троттера | n! | обмен соседних элементов |
| Треугольник Паскаля | C(n,k) | суммы двух элементов над строкой |
| Числа Каталана | C(2n,n)/(n+1) | — |
| Числа Белла | B(n) | треугольник Белла |
| Числа Стирлинга | S(n,k) и c(n,k) | — |
| Беспорядки | !n | — |
| Звёзды и перегородки | C(n+k−1,k−1) | — |

Наборы порождаются лениво: 12! — почти полмиллиарда перестановок, в памяти живёт ровно одна.

Алгоритмы лежат в пакете `vol9`: `Combinatorics`, `JohnsonTrotter`, `HeapPermutations`, `Subsets`,
`Partitions`, `GrayCode`, `PascalTriangle`, `Catalan`, `Bell`, `Stirling`, `Derangements`,
`StarsAndBars`.

Прикладная задача раздела — криптарифметические ребусы «ОДИН + ОДИН = МНОГО»: перебор
подстановок цифр под буквы. Реализация лежит в пакете `vol9.yasymb`.
