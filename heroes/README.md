# heroes

Два независимых приложения, у которых нет общего кода — только общий предок в дереве сборки.

| Модуль | Что это | Точка входа |
|---|---|---|
| [game](game) | Пошаговый бой на сетке 11×15 со Swing-интерфейсом | `ru.mifi.practice.voln.heroes.Main` |
| [web](web) | Чат-комнаты на Spring Boot: SSE, Telegram-бот, JWT | `ru.mifi.practice.voln.Application` |

К программе курса модуль отношения не имеет: это площадка для прикладных задач.
Ближе всего к курсу игра — в ней поиск пути по сетке (раздел 8) и очередь ходов на куче (раздел 9).
