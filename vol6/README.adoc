= Разделы 9 и 13. Куча и деревья

|===
| Пакет | Что внутри

| `tree` | обобщённое дерево, обходы-визиторы, куча, центр, центроид, диаметр
| `tree.search` | двоичное дерево поиска, AVL, красно-чёрное дерево

| `tree.paths` | наименьший общий предок, слияние путей
| `tree.visitors` | подсчёт узлов, глубины, эйлеров обход, тайминги поддерева
|===

== Куча (раздел 9)

`Heap.Minimum` — минимум-куча на массиве с нульиндексной адресацией:
parent(i) = (i−1)/2, left(i) = 2i+1, right(i) = 2i+2.
Вставка и извлечение — O(log n), чтение минимума — O(1).
Пирамидальная сортировка поверх той же идеи лежит в `vol3`.

== Деревья поиска (раздел 13)

|===
| Реализация | Гарантия высоты

| `BinarySearchTree` | нет: отсортированный вход вырождает дерево в список
| `AVL` | разница высот поддеревьев не больше единицы
| `RBT` | высота не больше 2·log(n+1)
|===

`Main` в пакете `tree.search` печатает число шагов поиска — видно, как балансировка спасает
от вырождения.

== Формат файла дерева

Построчно `владелец:{левый, правый}`. Пример в `src/main/resources/standard.tree`.

== Задание

`Center` помечен вопросом «Почему реализация не правильная?»: центр дерева определяется для
неориентированного графа, а здесь обрезаются только листья корневого двоичного дерева.
