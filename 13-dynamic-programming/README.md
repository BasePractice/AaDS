# Раздел 14. Динамическое программирование

Задача разбивается на перекрывающиеся подзадачи, каждая решается один раз, результат сохраняется.

| Пакет | Задача | Сложность |
|---|---|---|
| `fibonacci` | числа Фибоначчи: рекурсия, мемоизация, табуляция | O(2^n) против O(n) |
| `distance` | расстояние Левенштейна: рекурсия и таблица Вагнера—Фишера | O(n·m) |
| `subsequence` | наибольшая общая подпоследовательность | O(n·m) |
| `wildcard` | сопоставление с `*` и `?`, разбор аббревиатур | O(n·m) |
| `backpack` | рюкзак 0/1 | Θ((n+1)(W+1)) посещений ячеек |

Два подхода к одной идее: мемоизация идёт сверху вниз рекурсией с кешем, табуляция — снизу
вверх заполнением таблицы. `Main` печатает время и число операций, так что разницу между
наивной рекурсией и мемоизацией видно на глаз.

## Практика. Рюкзак 0/1 и двоичная запись ёмкости

Откройте `Backpack.Classic.putting` и тесты `BackpackTest` в пакете
`ru.mifi.practice.vol7.backpack`. Каждый предмет можно взять один раз.
В Java вес хранится в `weight`, ценность — в `needed`.

1. Запишите три предмета `A=(2,3)`, `B=(3,4)`, `C=(4,5)` в формате
   (вес, ценность). Вызовите `new Backpack.Classic(5).putting(items)`.
   Сложите вес и ценность выбранных предметов. Предскажите ответы для
   порогов ценности 7 и 8. Сверьте с `checksThreshold`.
   Ожидается набор A и B, вес 5, ценность 7, ответы «да» и «нет».
2. Для `[2,3,7]` задайте каждому предмету одинаковые вес и ценность
   и положите вместимость и порог равными цели. Допишите проверку
   для цели 7 рядом с примерами в `reducesSubsetSum`. Для целей
   5, 6 и 7 ожидаются ответы «да», «нет», «да» соответственно.
3. Оставьте предметы A, B и C и порог 12. Увеличивайте ёмкость
   `W` по таблице. Передайте в перегрузку `putting` счётчик
   `visits::incrementAndGet`, как в `countsVisitedCells`.
   Сравните его значение с `(n+1)(W+1)`: внутренний цикл посещает
   также строку и столбец с индексом 0. Длину записи проверьте
   выражением `Integer.toBinaryString(W).length()`.

| W | Биты записи W | Посещения | Оптимальная ценность |
|---:|---:|---:|---:|
| 15 | 4 | 64 | 12 |
| 31 | 5 | 128 | 12 |
| 63 | 6 | 256 | 12 |
| 127 | 7 | 512 | 12 |

Добавьте строку для `W=255` в тест и объясните результат.
При 8 битах должно быть 1024 посещения, ценность по-прежнему 12.
Как правило `W=2ᵇ−1` описывает рост числа столбцов?

Из корня репозитория на JDK 17:

```sh
mvn -pl 13-dynamic-programming -am -Dtest=BackpackTest -Dsurefire.failIfNoSpecifiedTests=false test
mvn -pl 13-dynamic-programming -am verify
```

Для таблицы с числовой ценностью в каждой ячейке оценка `O(n·W)`
описывает число переходов. В `Backpack.Classic` ячейка хранит список
предметов. Сложение ценностей и копирование списка могут потребовать
до `O(n)` работы на ячейку. В эксперименте счётчик измеряет только
посещения.

Источник для NP-полноты задачи о точной сумме — [Р. Карп,
«Reducibility Among Combinatorial Problems», 1972](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf),
задача 18 и сведение из Exact Cover.
