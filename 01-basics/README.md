# Разделы 1–2. Асимптотика и линейные структуры данных

| Пакет | Тема |
|---|---|
| `bigo` | классы сложности: O(1), O(log n), O(n) на живых примерах |
| `array` | динамический массив: `StandardArray` на массиве, `LinkedArray` на двусвязном списке |
| `stack` | стек LIFO поверх `Array` |
| `queue` | очередь FIFO поверх `Array` |
| `cbs` | правильная скобочная последовательность — стек в деле |
| `rpn` | обратная польская запись — снова стек |

Сортировки для сравнения по числу шагов лежат в `05-sorting-search` (`MainSort`), наивный Фибоначчи
со счётчиком вызовов — в `13-dynamic-programming` (`Fibonacci.Recursion`).

## Стоимость операций

| Операция | Массив | Список |
|---|---|---|
| `get(i)` | O(1) | O(n) |
| `set(i)` в конец | O(1) амортизированно | O(1) |
| `delete(i)` | O(n), сдвиг | O(n) на поиск, O(1) на связывание |

Очередь построена поверх массива, поэтому `dequeue` сдвигает весь массив за O(n).
Кольцевой буфер, дающий O(1), лежит в `90-sandbox` в пакете `buffer`.
